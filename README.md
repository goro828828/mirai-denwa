# 未来の自分から、着信です。

> いつか懐かしくなる今日を、あなたはどう過ごしますか。

**公開中：https://goro828828.github.io/mirai-denwa/**

10年後の自分と、不思議な公衆電話で話すスマートフォン向けのストーリー型Webゲームです。
React + TypeScript + Vite で作っています。

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に本番ビルド
```

## 遊びの流れ（実装済み）

0. **2回目以降**：最初に記入した内容（ニックネーム・性別・都道府県・いまの自分）は端末に保存され、2回目以降はカードを拾うと記入済みのカードが出る。「書き直す」（カードの裏）と「登録内容を変更」（タイトル）で変更できる
1. **タイトル画面**：山と田んぼの中に、ぽつんと公衆電話。街灯が照らしている（`src/components/TitleLandscape.tsx`）
   - 真横から見た平面的な構図：上から 山 → 奥の田んぼ → 路肩 → 横一本の道 → 手前の田んぼ。電話ボックス・街灯・電柱は道の奥側の路肩に立つ。稲は線を使わず、平らな形で描く
   - 明かりがついている街灯には、虫が寄ってきて回る。昼（朝・昼の晴れ・くもり）は、カラスが空を右から左へ横切る（「アニメーションを減らす」設定では出さない）
   - 時間帯（朝・昼・夕方・夜）で空の色・太陽・月・星が変わり、夕方・夜と雨・雷の日は街灯と電話ボックスに明かりがつく
   - 天気（晴れ・くもり・雨・雷雨・雪）で雲・雨・雪・稲光が変わる。雪の日は田んぼと山が雪に覆われる
   - 季節で田んぼが変わる：春（3〜5月）＝水を張った田んぼと苗／夏（6〜8月）＝青々とした稲／秋（9〜11月）＝実った稲穂と色づく山／冬（12〜2月）＝刈り取ったあとの切り株だけ
   - 天気は、登録した都道府県の予報（位置情報がすでに許可されていれば現在地）。タイトル画面では位置情報の許可をたずねない
   - URL に `?landscape=季節,時間帯,天気`（例：`?landscape=winter,night,snow`）をつけると、その組み合わせを確かめられる
：帰り道の短い導入文のあと、落ちているカードをタップして拾う → 裏返す
2. **カードに記入**：カードの記入欄に1項目ずつ書きこむ（ニックネーム／性別／都道府県／いまの自分）
   - カード上の欄をタップすると、その項目を書き直せる。前回の入力は端末に下書きとして残る
3. **公衆電話**：受話器をあげる → カードをスワイプかタップで差し込む → 「10年後の今日」の日付が自動でダイヤルされる → 呼び出し音
4. **通話**：通話の回数で会話が変わる。1回目＝初めての電話／2回目＝再会（前回の話題や日数に触れ、「あの電話も、もう懐かしい」と語る）／3回目以降＝いつもの電話（「こうして話すの、◯回目だね」）。あなた側の選択肢も「また、あなた？」「いつもの？」のように変わる。1〜3回目の相手は10年後、4回目以降は10〜60年後から抽選（履歴が10件たまるごとに次の1回は10年前か100年後）
   - 通話履歴が10件・20件…たまった次の1回は、**10年前の自分か100年後の自分**（自動で抽選）。10年前の自分は視点が逆で、「そっちから見たら、こっちの毎日って、もう懐かしいのかな」と未来のあなたに話しかける。100年後の自分は、遠くから届くような静かな話し方
   - 入力欄を開いても画面はずれず、拡大もされない（通話画面を、キーボードを除いた見えている範囲に固定）
   - 電話の相手は、**10・20・30・40・50・60年後の自分のどれか**（カードを拾うたびにランダム）。ダイヤルする日付・画面の表示・カードの「◯年後の◯◯より」もそれに合わせて変わる
   - 何回目の電話かは、あなたが言う（「これで◯回目だね」）。50・60年後の自分は何回目か覚えておらず（「ええと……何回目だったかな」）、あなたが教えてあげる
   - **あなた側の選択肢は、回数を重ねるほどフランクになる**（4段階：1回目＝ていねい／2回目＝少しやわらかい／3〜5回目＝くだけた言い方／6回目〜＝友だちのような調子。例：「いつも通りの、普通の日」→「いつも通り。ふつーの日」、「ありがとう」→「いつもありがとね」）。選んだ意味（value）は同じなので、会話の分岐や最後のメッセージは変わらない。`src/story/text.ts` の `me()`
   - 話し方は3段階：10年後＝気さく／20・30年後＝落ち着いた大人／40〜60年後＝年を重ねた穏やかな話し方（関西弁・博多弁・標準語それぞれ）。年齢は口調や視点で感じさせ、未来の出来事は断定しない
   - 「最近の◯◯」の質問枠には、5つの話題（おいしかったもの／笑ったこと／きれいだった景色／よく聴く音楽／よく行く場所）からランダムで1つが入る。形と往復の数はどの話題でも同じ
   - 未来の自分は、プレイヤーの「今」を、すでに懐かしい思い出として語る。途中で「少しだけ画面から目を離して、まわりを見てみて」と促し、今日を先回りして懐かしむ場面がある
   - 最初の「もしもし？」だけ音声（ファイルがあれば再生）。あとは字幕で進む。選択肢と任意の自由入力（3か所：食べたもの・夢中なもの・今の気持ち）
   - 未来の自分は、回答への返事のあとに、ランダムで「確かにそうだった気がする」と振り返る（1回の通話で最低1回）
   - 画面を長押ししている間は、早送りになる（キーボードではスペースキーを押している間）
   - 往復は10〜11回。未来の自分の返事は、原則1〜2文
   - 残り度数が減っていき、少なくなると最後のメッセージへ進む
5. **最後の言葉**：回答（今日の気持ち・よく話す人・夢中なもの）によって変わる
   - 「今の気持ち」を書いた場合は、その言葉の手がかり（例：「寂しい」「疲れた」「楽しみ」「ありがとう」）からメッセージを選ぶ。全9種類
   - 書いた文章そのものは通話中にだけ引用し、共有カードには載せない
6. **カード排出**：カードには、通話の内容に合った挿絵（13種類＋公衆電話。`src/lib/illustrations.ts`）が入る。話題の絵 → 天気の絵 → 公衆電話 の順に選ぶ。特別な回は砂時計。「ピピピ」という音とともにカードが戻る。拾ったときにはなかった文字が印字されている
7. **保存・共有**：「写真に保存」— iPhone・iPad は共有シートを開き、「画像を保存」で写真アプリへ（Webページは写真アプリに直接書きこめないため、OSの保存メニューを使う）。Android はダウンロードで写真（ギャラリー）アプリの「Download」へ。パソコンは画像のダウンロード。共有は Web Share（画像つき）、非対応の端末では X の投稿画面へのリンクを出す
8. **通話履歴**：一覧・詳細・カード画像の再保存・1件削除・全件削除（どちらも確認あり）
   - 「一覧」（最初の表示）と「カレンダー」を切り替えられる。カレンダーでは、電話した日にその日のカードの挿絵がスタンプのように入り、1日に2回以上なら回数が出る。日付をタップすると、その日の記録が下に並ぶ（`src/components/HistoryCalendar.tsx`）

## 環境音

`public/audio/ambient/` に4つ入っています。出典とライセンスは [CREDITS.md](public/audio/ambient/CREDITS.md) と、ゲーム内の「設定 → 環境音のクレジット」にあります。

| ファイル | 天気 | 元の録音 | ライセンス |
|---|---|---|---|
| clear-day.mp3 | 晴れ・昼（小鳥） | エストニアの森の夜明けの合唱（105分） | Public Domain Mark |
| clear-night.mp3 | 晴れ・夜（虫） | イタリア・リグーリアのコオロギと夜の音（71分） | Public Domain Mark |
| rain.mp3 | 雨 | エストニアの田園の雨（57分） | CC BY-SA 3.0（クレジット表示が必要） |
| thunder.mp3 | 雷雨 | シチリアの雷雨（40分） | Public Domain Mark |

- どれも元の録音は15分以上です。各録音から、音量の急な変化が少ない連続した20分を切り出しています（短い音源の繰り返しではない）。
- モノラル・80kbps の MP3（各約12MB）。ラウドネスをそろえ、曲の終わりの6秒で先頭へクロスフェードしてループします。
- 「もしもし？」の音声ファイル（`public/audio/voice/moshimoshi-*.mp3`）はまだ入っていません。無い間は字幕だけで進みます。

## BGM

`public/audio/music/bgm.mp3`「遠い放課後」は、このゲームのために作ったオリジナル曲です（ヘ長調・約2分20秒。ピアノの分散和音・オルゴールの旋律・薄い弦）。

- 楽譜は `tools/bgm/compose.py`、音にする手順は `tools/bgm/render.sh`（FluidSynth と FluidR3_GM サウンドフォント〔MIT License〕で鳴らし、テープのような柔らかさを足している）
- 曲の終わりで先頭へクロスフェードしてループします
- ブラウザの決まりで、画面に一度触れるまでは音が出ません。タイトル画面では、最初に画面に触れたときから流れはじめます

## 公開のしかた（GitHub Pages）

いまは GitHub Pages で公開しています。`gh-pages` ブランチの中身が、そのまま https://goro828828.github.io/mirai-denwa/ に出ます。

更新するときは `npm run build` で `dist/` を作り、その中身（と空の `.nojekyll`）を `gh-pages` ブランチに置き換えて push します。共有カードに載るURLは `.env.production` の `VITE_SITE_URL` で決まります。

## 別の公開方法：Netlify Drop

`npm run build` で作られる `dist/` フォルダを、そのままアップロードするだけで公開できます。サーバー側の設定は不要です。

1. https://app.netlify.com/drop を開き、無料アカウントでログインする（ログインせずに公開すると、1時間で消えます）
2. `dist` フォルダ（または同梱の `mirai-denwa-site.zip` を展開したフォルダ）を、画面にドラッグ＆ドロップする
3. 数十秒で `https://〜.netlify.app` のURLが発行される。スマートフォンで開いて遊べる

公開後のURLが決まったら、`.env` に `VITE_SITE_URL=https://〜.netlify.app` と書いて `npm run build` し、もう一度アップロードすると、共有カードと共有文にURLが載ります。

## 公開（Vercel など）

- ビルドの出力先は `dist/` です（`npm run build`）。
- 環境変数 `VITE_SITE_URL` に公開URLを設定すると、共有カードと共有文にそのURLが入ります。

## プライバシー

- 入力した内容・回答・履歴は、すべてこの端末のブラウザ（localStorage）に保存されます。サーバーには送りません。
- 外部に送るのは、天気を取得するための **都道府県の予報区コード（気象庁）** と **緯度・経度（Open-Meteo）** だけです。
- 位置情報は任意です。許可された場合だけ、約1km単位に丸めた緯度・経度を天気の取得に使います。端末にも履歴にも保存しません。設定画面でオフにできます。
