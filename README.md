# 未来の自分から、着信です。

> いつか懐かしくなる今日を、あなたはどう過ごしますか。

10年後の自分と、不思議な公衆電話で話すスマートフォン向けのストーリー型Webゲームです。
React + TypeScript + Vite で作っています。

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に本番ビルド
```

## 遊びの流れ（実装済み）

1. **カードを拾う**：帰り道の短い導入文のあと、落ちているカードをタップして拾う → 裏返す
2. **カードに記入**：カードの記入欄に1項目ずつ書きこむ（ニックネーム／性別／都道府県／いまの自分）
   - カード上の欄をタップすると、その項目を書き直せる。前回の入力は端末に下書きとして残る
3. **公衆電話**：受話器をあげる → カードをスワイプかタップで差し込む → 「10年後の今日」の日付が自動でダイヤルされる → 呼び出し音
4. **通話**：最初の「もしもし？」だけ音声（ファイルがあれば再生）。あとは字幕で進む。選択肢と任意の自由入力（3か所：食べたもの・夢中なもの・今の気持ち）
   - 未来の自分は、回答への返事のあとに、ランダムで「確かにそうだった気がする」と振り返る（1回の通話で最低1回）
   - 画面をタップすると、次の台詞まで早送りできる
   - 残り度数が減っていき、少なくなると最後のメッセージへ進む
5. **最後の言葉**：回答（今日の気持ち・よく話す人・夢中なもの）によって変わる
   - 「今の気持ち」を書いた場合は、その言葉の手がかり（例：「寂しい」「疲れた」「楽しみ」「ありがとう」）からメッセージを選ぶ。全9種類
   - 書いた文章そのものは通話中にだけ引用し、共有カードには載せない
6. **カード排出**：「ピピピ」という音とともにカードが戻る。拾ったときにはなかった文字が印字されている
7. **保存・共有**：PNG保存、Web Share（画像つき）。非対応の端末では X の投稿画面へのリンクを出す
8. **通話履歴**：一覧・詳細・カード画像の再保存・1件削除・全件削除（どちらも確認あり）

## 仕様との対応

### 実装済み

| 仕様 | 実装 |
|---|---|
| カード操作型の記入フォーム | `src/scenes/Intro.tsx` `src/components/PhoneCard.tsx` |
| 公衆電話の操作・接続演出 | `src/scenes/Phone.tsx` `src/components/Payphone.tsx`（CSSで描画。実在の機種を模したものではない） |
| 分岐型の会話シナリオ | `src/story/script.ts`（会話の全文はこのファイルだけにまとめてある） |
| 方言（関西弁・博多弁を参考にした話し方・標準語） | `src/data/prefectures.ts` の `dialectOf` で分類 |
| 天気の取得（都道府県庁所在地を代表地点にする） | `src/lib/weather.ts`。代表地点であることを画面とカードに表示。取得できなければ天気を推測しない |
| 天気と時間帯に応じた環境音（クロスフェードでループ） | `src/lib/sound.ts`（音源ファイルは未同梱。下記参照） |
| 通話中は環境音を控えめにする | `sound.duck()` |
| 音量・ミュート・アニメーションを減らす設定 | 右上のボタンと設定画面。端末の「視差効果を減らす」設定にも従う |
| 効果音（発信音・プッシュ音・呼び出し音・警告音・終話音・排出音） | Web Audio で合成（ファイル不要） |
| PNGカード（タイトル・通話日時・ニックネーム・地域・天気・最後のメッセージ） | `src/lib/cardImage.ts`。回答の全文は載せない |
| localStorage の履歴 | `src/lib/storage.ts` |
| 背景が時間帯（朝・昼・夕・夜）と雨で変わる | `src/index.css` |

## 音声ファイルの置き場所

ファイルが無くても、ゲームは無音または字幕で最後まで遊べます。

```
public/audio/ambient/clear-day.mp3     晴れ・昼   （候補：Garden Background）
public/audio/ambient/clear-night.mp3   晴れ・夜   （候補：Evening meadow ambience）
public/audio/ambient/cloudy-day.mp3    曇り・昼   （候補：Suburban Atmosphere）
public/audio/ambient/cloudy-night.mp3  曇り・夜   （候補：Window wind moans long）
public/audio/ambient/rain.mp3          雨         （候補：Rain sounds_long unedited）
public/audio/ambient/thunder.mp3       雷雨       （候補：Thunder and rain 20 Minutes）
public/audio/voice/moshimoshi-male.mp3
public/audio/voice/moshimoshi-female.mp3
public/audio/voice/moshimoshi-neutral.mp3   （任意）
```

- 環境音は **元の録音が15分以上の音源** をそのまま置いてください。全体を一度に読み込まず、ストリーミングで再生します。
- 曲の終わりの6秒間で、曲の先頭へクロスフェードします。
- 読み込みを軽くするため、モノラル・96kbps程度のMP3への変換をおすすめします。例：

  ```bash
  ffmpeg -i input.wav -ac 1 -b:a 96k public/audio/ambient/rain.mp3
  ```
- Freesound の候補を採用する前に、各ページで **ライセンス（CC0かどうか）・実際の長さ・音質** を確認してください。この開発環境からは Freesound に接続できなかったため、確認もダウンロードもしていません。

## 公開（Vercel など）

- ビルドの出力先は `dist/` です（`npm run build`）。
- 環境変数 `VITE_SITE_URL` に公開URLを設定すると、共有カードと共有文にそのURLが入ります。

## プライバシー

- 入力した内容・回答・履歴は、すべてこの端末のブラウザ（localStorage）に保存されます。サーバーには送りません。
- 外部に送るのは、天気を取得するための **都道府県の代表地点の緯度と経度** だけです。位置情報の許可は求めません。
